# 재단견적

고객 시안(벡터 파일·규격 PDF)을 불러와 제품 형상을 고르면, 판재(아크릴판 등)에 몇 장이 필요한지 배치 계산하고 대략적인 견적을 내주는 웹 프로그램입니다.

- 앱 형태 결정 근거와 단계별 계획: [docs/PLAN.md](docs/PLAN.md)
- 현재 단계: **1단계(MVP)** — 시안 불러오기 → 판재 장수 계산 → 대략 견적까지 동작

## 실행

Node.js 20 이상이 필요합니다.

```bash
cd web
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 배포용 정적 파일 → web/dist
npm test           # 단위 테스트
```

`web/dist` 폴더는 정적 파일만 있으므로 사내 웹서버(IIS 등)에 그대로 올리면 됩니다. 서버 프로그램은 필요 없습니다.

## 사용 순서

1. **① 시안 · 제품 선정**
   - 시안 파일(SVG, DXF, PDF, AI)을 끌어놓습니다. `samples/` 폴더에 시험용 파일이 있습니다.
   - 닫힌 윤곽이 형상으로 인식됩니다. 도면을 클릭하거나 목록에서 선택한 뒤 **선택 형상 → 제품 추가**를 누릅니다. 같은 형상은 1개 제품으로 묶이고 개수가 수량이 됩니다.
   - 도면 테두리·치수선이 제품을 감싸고 있으면 그 윤곽을 선택해 **선택 제외**합니다. (PDF 페이지 테두리는 자동 제외)
   - 절단선 레이어/색상만 남기면 인식이 정확해집니다.
   - 축척 도면은 **배율**을 바꾸거나, 형상 1개를 선택하고 실제 가로 길이를 입력해 맞춥니다.
   - 오른쪽 제품 목록에서 크기(비율 고정 가능)·수량·판재·회전 허용을 수정합니다. 도면이 없으면 **직접 입력**으로 사각 제품을 추가합니다.
2. **② 판재 배치** — 부품 간격·판 여백을 정하면 판재별 필요 장수, 효율, 판별 배치도가 바로 계산됩니다.
3. **③ 견적서** — 자재비·가공비·작업비·이윤·부가세가 정리됩니다. 인쇄/PDF 저장, CSV(엑셀) 내보내기가 가능합니다.
4. **판재 · 단가 설정** — 판재 규격·장당 단가·가공 단가(원/m), 작업비, 이윤율, 최소 금액, 추가 비용 항목을 등록합니다. 기본 단가는 **예시값**이니 실제 단가로 바꿔 쓰세요.

판재·단가 설정과 작업 중인 제품 목록은 브라우저에 자동 저장됩니다. 견적 건별로 보관하려면 상단 **작업 저장**(JSON)을 쓰세요.

## 견적 계산 방식

| 항목 | 계산 |
|---|---|
| 자재비 | 판재별 사용 장수 × 장당 단가 (설정에 따라 마지막 장은 사용 비율만큼, 1/4·1/2장 단위 올림) |
| 가공비 | 가공 길이(외곽 + 구멍 + 내부선, m) × 판재별 가공 단가 |
| 개당 가공비 | 부품 수 × 단가 |
| 기본 작업비 / 추가 항목 | 건당·개당·장당·m당·㎡당 |
| 공급가액 | 원가 합계 × (1 + 이윤율), 최소 작업 금액 적용, 금액 단위 처리 |
| 제품별 단가 | 자재비는 외접 사각형 면적 비율, 가공비는 제품 가공 길이, 건당 비용은 원가 비율로 나눈 **참고값** |

## 1단계의 한계

- 배치는 **부품 외접 사각형 기준**입니다. 원·별·글자처럼 빈 공간이 많은 형상은 실제보다 판재가 많게 나올 수 있습니다 (실제 윤곽 배치는 2단계).
- EPS, DWG, 이미지(스캔) PDF는 형상을 읽지 못합니다. PDF/SVG/DXF로 저장하거나 규격을 직접 입력하세요.
- 일러스트레이터 글자는 **윤곽선 만들기(Create Outlines)** 후 저장해야 형상으로 인식됩니다.

## 폴더 구조

```
docs/PLAN.md            앱 형태 제안, 단계별 계획
samples/                시험용 시안 (SVG, DXF, PDF)
web/
  src/core/             계산 로직 (화면과 분리된 순수 함수)
    importers/          svg.ts, dxf.ts, pdf.ts — 파일 → 공통 도면 모델(mm)
    drawing.ts          선 연결, 형상(부품) 인식, 동일 형상 판별, 규격 텍스트 추출
    model.ts            제품·판재·단가 설정 구조와 기본값
    nest.ts             MaxRects 사각 배치, 판당 최대 수량
    pricing.ts          견적 계산
  src/ui/               React 화면
  tests/                단위 테스트 (Vitest)
  scripts/make-samples.mjs  샘플 파일 생성
```
